# innercanvas

A cloud-based personal wellness and reflection platform. innercanvas is a quiet digital space for reflection, awareness and personal growth.

## Features
- Mood check-in using sky-inspired "inner weather"
- Gentle writing prompts that change with your mood
- Guided breathing orb
- Reflections saved locally in the browser (preview)
- Light and dark themes, with reduced-motion support

## Tech
Plain HTML, CSS and JavaScript in a single `index.html`. No build step.

## Run locally
Open `index.html` in any browser.

## Deploy
Hosted as a Static Site on Render, with no build command and the publish directory set to `.`

## Note
innercanvas supports self-reflection and is not a substitute for professional care.
